# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

We aim to acknowledge a report within a week and to agree a fix and disclosure date with you. Please give us a reasonable time to fix the problem before you share details.

## Supported versions

Only the latest version of the app on the default branch is supported.

How the project is protected (threat model, CI checks, dependency waivers) is described in [docs/security.md](docs/security.md).
