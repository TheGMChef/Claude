# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Linear, with Notion influence
- **Notes:** The product look is "Ink & Index": warm paper, index cards, and hand-drawn ink on borders and marks only, never on text. Linear sets density, restraint and speed. Notion sets warm paper, editorial type and calm spacing. Ink borders and 44px tablet targets win over Linear's sharp 1px borders. Buttons and menus should feel satisfying: a clear press-down (about 100ms), no layout shift, a short soft menu open, and all motion off under reduced-motion.

## Banned anti-aesthetics

- Glassmorphism or `backdrop-filter` without a strong edge
- Pastel pill badges for ordinary metadata
- Decorative gradients and neon glow borders
- Rainbow gradients on normal buttons
- Cartoon empty-state illustrations
- Nested scrollbars and icon bloat inside inputs
- Emoji as UI icons
- Hand-drawn ink applied to text

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text, 3:1 for large text and borders, in both light and dark themes
- **Touch / focus:** 44x44px targets, a 2px pencil-blue focus ring, `prefers-reduced-motion` respected

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Verb-first buttons ("Pin to scene", never "OK"). Errors never blame the DM and always offer a next step.

## Icon library

- **Library:** Project SVG
- **Package / path:** `apps/web/src/kit/Icon.tsx`
- **Notes:** One set only. New icons match the style: 22px box, 1.7 stroke, round caps and joins. No emoji as icons and no mixing in another library.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
